# Replay/fallback implementation excerpts

These byte-preserved files specify the request scheduler, zero/hold deadline commands, archived latency matching, case plan, and saved-metric checks used in the completed replay/fallback batch. They are supplied for inspection under the repository's MIT code license (reference records: CC BY 4.0).

This is a source excerpt, not a standalone simulation package. The worker, original project, model weights, full caches, runtime configuration, and full returned raw records are not included. Use `python -B scripts/reproduce_all.py` at the repository root to analyze the compact saved outcomes. No experiment is started by that command.
