The FP32 PINO predictor has three layers of width 32, eight Fourier modes per axis, reflection padding 8, 14 input channels, 90 conditioning features, and 20 predicted steps. Its parent training set contains 5,000 windows from 40 episodes; validation uses 128 windows from eight episodes. These windows start from true temperature fields restricted to $32\times32$ and actual actuator states, whereas controller evaluation uses observed or estimated fields. The executed budget is 500 supervised and 100 paired steps, but the transferred validation-best checkpoint is supervised step 200. It therefore precedes the paired action-difference training. Supervision combines Smooth-L1 on temperature fields scaled by 10~K with a squared discretized heat-equation residual normalized by $40{,}000$. The physics coefficient ramps as $0.1\min(1,t/500)$, reaching 0.04 at the retained checkpoint. Balance projection is applied before these losses. Supervised optimization uses AdamW, learning rate $5\times10^{-4}$, effective batch 64, weight decay 0.01, gradient clipping at one, and a 5\% learning-rate ramp.
